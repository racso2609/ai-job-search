# /upskill - Skill Gap Analysis and Learning Plan

> **opencode runtime note.** This command drives the repo's `upskill` skill (`.claude/skills/upskill/SKILL.md`). Load it via the `skill` tool with `name: upskill`, then execute its workflow exactly. `$ARGUMENTS` passes through (empty for the full profile-vs-tracker analysis, or a single posting URL as `/upskill <URL>`).

Analyze the gap between the candidate profile, tracked and ranked job postings, and produce a prioritized skill-gap heatmap with a learning plan.

Arguments (optional): $ARGUMENTS
